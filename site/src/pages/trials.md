증강을 여러 장 쌓은 팀 앞에서 바닐라 엔더 드래곤은 몇 대 만에 쓰러집니다. 회차 내내 몸을
불려 온 팀에게 마지막 보스가 회차에서 가장 쉬운 구간이 되는 셈입니다. **드래곤 시련**은 그
마지막 보스를 마지막 보스답게 만드는 팀 설정입니다. 시련을 켜면 드래곤이 인원에 비례해
단단해지고, 전투가 진행될수록 시련 카드가 한 장씩 쌓이며, 체력 30% 에서는 **최후의 저항**이라는
별개의 보스전이 열립니다.

## 켜는 법

**팀 설정이고, 기본값은 끔입니다.** 팀을 만들 때 팀 화면의 「드래곤 시련」을 켜거나 명령으로
켭니다. 팀 이름은 언제나 맨 끝에 적습니다.

```text
/shareteam create dragontrials on <팀 이름>
```

다른 설정과 함께 적어도 됩니다 — 설정 전체는 [게임 시작](/sharedfate/guide/start)에 있습니다.

- **만든 뒤에는 바꿀 수 없습니다.** 켜고 끄는 명령이 따로 없습니다. 바꾸려면 팀을 해체하고 다시 만듭니다
- 지금 값은 `/shareteam status` 의 「드래곤 시련=」 줄에서 봅니다
- 끄면 카드·고정 시련·기본 패시브가 전부 꺼지고, 드래곤도 바닐라 그대로입니다
- 시련을 켠 팀은 공유 레벨 상한이 40 이 아니라 50 입니다
- 서버에 팀이 여럿이어도 시련은 한 번에 한 팀입니다. 시련을 켠 팀이 엔드에서 싸우는 동안 다른 팀이 들어오면, 그 팀의 전투는 시련 없이 바닐라 드래곤전으로 열립니다

## 드래곤 체력

| | 드래곤 최대 체력 |
|---|---|
| 시련 끔 | 200 (바닐라) |
| 시련 켬 | 팀 인원 × 600 — 2인 1200 · 3인 1800 · 4인 2400 |

인원은 접속자가 아니라 **팀 명단**으로 셉니다. 인원당 값은 서버 설정 `dragonHealthPerMember`
(기본 600)로 바꿀 수 있습니다 — [설치](/sharedfate/guide/install) 안내를 보십시오.

## 엔드에 들어가면

1. **팀 전원이 엔드로 불려 갑니다.** 누군가 엔드에 들어가면 3초 예고 뒤 나머지 팀원이 소환되고, 도착한 뒤 3초는 무적입니다
2. **수락창.** 「시련이 곧 시작됩니다」 창이 뜹니다. 리더가 확인을 누르면 팀 전원이 중앙 단상으로 모입니다. 말리는 창이 아니라 판이 바뀌기 전에 팀을 한 번 멈춰 세우는 창이라, 단추는 확인 하나뿐이고 리더가 60초 안에 누르지 않아도 그대로 진행됩니다
3. **입장 연출.** 크리스탈이 사라졌다가, 드래곤이 중앙 상공에 나타나고, 크리스탈이 되살아납니다
4. **첫 룰렛.** 연출이 끝나면 입장 자리의 시련 카드가 뽑힙니다

## 시련이 오는 방식

**시련은 시간이 아니라 전투 진행도로 옵니다.** 크리스탈을 깨거나 드래곤 체력을 깎아 정해진
자리에 닿을 때마다 한 장씩 쌓이고, 전투가 끝날 때까지 남습니다. 체력 막대만 보면 다음 시련이
언제 올지 알 수 있고, 빨리 깎을수록 빨리 받습니다.

- **룰렛 자리에서는 판이 멈춥니다.** 증강 선택처럼 화면이 뜨고 카드 이름이 돌다 멈춥니다. 룰렛과 읽는 시간을 합쳐 약 17초 동안 피해도 들어오지 않습니다
- **시련에는 보상이 없습니다.** 고르는 것이 아니라 뽑는 것입니다
- **같은 자리는 한 번만 셉니다.** 드래곤이 크리스탈로 회복해 체력이 문턱을 오르내려도 다시 뽑지 않습니다
- 한꺼번에 여러 문턱을 지나면 룰렛이 겹쳐 뜨지 않고 하나씩 차례로 뜹니다

## 시련 카드 16장

카드가 걸리는 자리는 다섯입니다. 룰렛 자리에서는 그 자리의 카드 중 한 장이 뽑힙니다. 설명은
뽑힌 순간 화면에 뜨는 글을 줄인 것입니다.

| 자리 | 카드 | 설명 |
|---|---|---|
| 입장 | 자리 폭격 | 12초마다 한 사람이 2초 전에 있던 자리가 터집니다. 맞으면 하늘로 떠오릅니다 |
| | 기둥 화염구 | 10초마다 가장 가까운 흑요석 기둥에서 불덩이가 날아옵니다. 2초 동안 궤적이 보입니다 |
| | 엔더 파동 | 20초마다 중앙에서 바닥 고리가 퍼집니다. 땅을 딛고 있으면 바깥으로 밀려나고 잠시 묶입니다 |
| | 굳는 손 | 30초마다 핫바 두 칸이 굳어, 그 칸의 물건을 휘두를 수도 쓸 수도 없습니다 |
| 첫 크리스탈 | 크리스탈 보호막 | 남은 크리스탈이 화살에 맞지 않습니다. 올라가서 깨야 합니다 |
| | 다시 선 쇠창살 | 모든 크리스탈에 쇠창살이 다시 생깁니다. 없던 탑에도 생깁니다 |
| | 표적 | 크리스탈을 깬 사람이 10초 동안 표적이 되어 구체 5발을 받습니다. 그다음 20초는 쉽니다 |
| | 연결된 수정 | 크리스탈을 부수면 가장 가까운 다른 크리스탈이 30초 동안 어떤 피해도 받지 않습니다 |
| | 수정 과충전 | 달아오른 크리스탈을 15초 안에 못 부수면 한 명에게 구체 10발이 날아옵니다. 블록 뒤에 숨으면 막힙니다 |
| 크리스탈 전멸 | 낙뢰 | 6초마다 아레나 열 곳에 번개가 떨어집니다. 떨어지기 전에 자리가 보입니다 |
| | 엔더폭풍 | 가장자리에서 중앙으로 소용돌이 둘이 밀려옵니다. 닿으면 아프고 바깥으로 밀려납니다 |
| | 메마른 세계 | 엔드의 물과 용암이 증발하고, 그 뒤로는 물·용암·서리눈을 놓을 수 없습니다 |
| 체력 80% | 착지 충격 | 드래곤이 착지할 때마다 중앙에서 충격이 세 번 퍼집니다. 땅을 딛고 있으면 맞고 멀리 밀려납니다 |
| 체력 50% | 부활 | 모든 크리스탈이 되살아납니다. 드래곤이 중앙 상공에서 그것을 지켜봅니다 |
| | 밤의 군세 | 주위 20블록 안의 엔더맨이 다섯 마리까지 20초 동안 적대가 되어 달려옵니다 |
| | 종말의 비 | 30초 동안 아레나 곳곳에 표시가 떴다가 떨어집니다. 표시된 자리에 서 있으면 크게 다칩니다 |

**체력 80% 의 「착지 충격」은 고정 시련입니다.** 카드가 한 장뿐이라 룰렛을 돌리지 않고 화면도
띄우지 않습니다. 그 순간 드래곤이 세졌다는 것을 소리와 화면 흔들림으로만 알립니다.

## 드래곤 기본 패시브

룰렛과 상관없이, 시련을 켠 팀의 드래곤이 처음부터 하는 것입니다.

- **연쇄 포격** — 40초마다 중앙을 지나는 두 줄 위에 빨간 원 스무 개가 뜨고, 4초 뒤 드래곤 쪽 끝부터 0.4초 간격으로 줄마다 하나씩 터집니다. **터진 자리에는 아무것도 남지 않습니다.** 선을 따라 도망치면 따라잡히니, 방금 터진 원 안으로 들어가십시오
- **착지** — 바닐라 드래곤은 크리스탈이 많이 살아 있으면 거의 내려앉지 않습니다. 시련의 드래곤은 크리스탈이 남아 있어도 꾸준히 착지하고, 체력 80% 뒤로는 더 자주 앉습니다. **착지하면 8초 동안 일어나지 않고, 그동안은 근접 피해만 들어갑니다**

## 최후의 저항 — 체력 30%

드래곤 체력이 처음 30% 아래로 내려가면 카드가 아니라 **별개의 보스전**이 열립니다.

- 그때까지 쌓인 시련이 전부 꺼집니다(「메마른 세계」의 설치 금지만 남습니다)
- 살아 있는 크리스탈과 엔더맨이 사라지고, **팀 체력이 가득 찹니다**
- 드래곤은 중앙에 내려앉아 다시 날아오르지 않고, 몸에 닿아도 피해가 없습니다 — 붙어서 때리는 싸움입니다

### 진입 연출

드래곤이 내려오고, 원 밖에 있던 사람이 안쪽으로 끌려 들어오고, 보라색 빛기둥 넷이 켜지며
드래곤 체력이 최대 체력의 20% 만큼 다시 차오른 뒤 「최후의 저항」이 뜹니다. 진입부터 첫 패턴
직전까지 약 11초 동안 **드래곤은 하늘색 반구 보호막에 싸여 피해를 받지 않고**, 팀도 같은 시간
무적입니다.

### 패턴

하나가 끝나면 2~4초 쉬고, 넷 중 하나를 무작위로 고릅니다. 같은 패턴이 연달아 나오지는 않습니다.

| 패턴 | 무엇을 하는가 |
|---|---|
| 날개 퍼덕이기 | 5초 동안 충격파 8번. 피해 없이 밀기만 합니다 |
| 부채꼴 브레스 | 바닥의 빨간 면으로 4초 예고한 뒤 90도·사거리 20칸을 태웁니다. 무장을 갖춰도 한 대에 전멸합니다 |
| 공허 흡입 | 드래곤 발밑에 검은 원이 생기고, 2초 예고 → 5초 빨아들임 → 터짐. 반대쪽으로 달리면 벗어나고 걷거나 서 있으면 끌려갑니다 |
| 십자 균열 | 십자 둘이 한꺼번에, 각도를 바꿔 두 번 터집니다. 맞으면 12칸 솟구치지만 그 낙하 피해는 없습니다 |

### 내내 도는 것

- **상시 번개** — 7.8초마다 드래곤 주변 열 곳에 떨어집니다. 맞은 사람만 1초 동안 느려집니다
- **반구 블록 파괴** — 1초마다 드래곤 주변 반경 25칸에서 섬 표면보다 높은 블록과 물·용암을 지웁니다. 블록을 쌓아 숨을 수 없습니다
- **안전지대** — 반경 42 → 32 → 22 → 12 로 세 번 줄어드는 원입니다. 걸어 나갈 수는 있지만 누가 밖에 있는 동안 팀이 초당 8 씩 피해를 받고, 마지막으로 줄어든 뒤로는 그 값이 5초마다 1.6 씩 오릅니다. 밖에 있는 사람에게만 심장 박동이 들립니다
- **오브젝트 파도** — 드래곤 체력 25% 와 10% 에 한 번씩, 인원(1~4인)에 따라 2/4/5/6개의 크리스탈이 떨어집니다. 박힌 뒤 2초부터 드래곤과 이어져, **부술 때까지** 초당 최대 체력의 0.5% 를 되돌립니다

이 단계에서 쓰러진 드래곤은 바닐라의 죽음 연출이 없습니다. 경험치·알·출구 포털은 그대로 나옵니다.

## 패턴 타이머

시련을 켠 팀은 드래곤 전투 중 **오른쪽 위, 상태이상 아이콘 바로 아래**에 다음 패턴까지 남은
시간이 보입니다.

- **패널** — 「다가오는 패턴」(최후의 저항에서는 「다가오는 것」). 줄마다 색 점 · 이름 · 남은 초 · 남은 비율 막대가 있고, 곧 올 것이 위에 섭니다. 착지처럼 시각이 정해지지 않은 것과 한 번으로 끝나는 카드는 나오지 않습니다
- **시전 막대** — 최후의 저항에서만, 보스바 아래 가운데에 뜹니다. 드래곤이 고른 패턴이 발동할 때까지 찹니다. 쉬는 동안 패널에는 「다음 패턴 · 무작위」만 보입니다
- 판이 멈추면 숫자도 멈춥니다. **F1** 이면 숨고, **F3** 화면이 덮으면 접힙니다
