접속한 뒤에 할 일은 셋입니다 — **팀을 만들고, 사람을 모으고, 시작합니다.**

명령으로도 되고, **인벤토리(E) 왼쪽 위의 단추**를 눌러 열리는 팀 화면에서도 됩니다.
`/shareteam` 은 `/st` 로 줄여 쓸 수 있습니다.

## 1. 팀을 만듭니다

```text
/shareteam create <팀 이름>
```

친 사람이 리더가 됩니다. 이름만 적으면 나머지는 전부 기본값입니다.

### 설정은 이때 한 번만 정합니다

여덟 가지를 만들 때 함께 적을 수 있고, **그 뒤로는 바꿀 수 없습니다.** 회차가 굴러가는 중에
규칙이 바뀌면 같은 회차의 앞뒤가 달라지기 때문입니다. 바꾸려면 팀을 해체하고 다시
만들어야 합니다.

```text
/shareteam create [perks on|off] [damagealert on|off] [deathalert on|off]
                  [difficulty on|off] [dragontrials on|off]
                  [health <20~40>] [swap off|<1~120>] [reroll <0~15>] <팀 이름>
```

| 설정 | 기본값 | 무엇 |
|---|---|---|
| `perks` | **켬** | 증강을 쓸지. 끄면 레벨이 올라도 카드가 안 나옵니다 |
| `health` | 서버 설정값 | 팀 공유 최대 체력. **20~40** 사이에서 정합니다 |
| `swap` | **5분** | 팀원 위치를 무작위로 뒤바꾸는 주기(분). `off` 로 끌 수 있습니다 |
| `reroll` | **3** | 증강 카드를 다시 뽑을 수 있는 회차당 횟수 |
| `difficulty` | 끔 | 30분마다 적대 몹이 **4%p 씩** 세짐 (최대 +100%, 엔더 드래곤 제외) |
| `dragontrials` | 끔 | 엔더 드래곤이 인원에 비례해 세지고 시련 카드가 뜸. 끄면 바닐라 드래곤전 |
| `damagealert` | 끔 | 팀원이 맞았을 때 알림과 화면 연출 |
| `deathalert` | 끔 | 팀원이 죽었을 때 알림 |

지금 값이 얼마인지는 `/shareteam status` 로 봅니다.

> **사망 알림을 끄면 죽은 기록이 채팅에도 서버 로그에도 남지 않습니다.** 모드가 사망
> 메시지를 지우는데, 서버 로그도 채팅을 받아 적는 자리이기 때문입니다. 나중에 전멸 원인을
> 쫓을 생각이라면 켜 두는 편이 낫습니다.

## 2. 사람을 모읍니다

```text
/shareteam invite <플레이어>
```

**수락 절차가 없습니다.** 리더가 치면 상대가 곧바로 들어옵니다. 그때 상대의 **개인 아이템은
있던 자리에 드랍되고 개인 경험치는 팀 공유 풀에 합쳐지므로**, 부르기 전에 미리 알려 주는
편이 좋습니다.

최대 네 명입니다.

> **사람은 시작하기 전에 다 모읍니다.** 시작한 뒤에는 초대가 막힙니다 — 도중에 들어오면
> 증강을 고르는 구간을 건너뛴 채로 남이 모은 인벤토리를 쓰게 되어, 같은 회차를 서로 다른
> 조건으로 겪습니다. 사람을 바꾸려면 팀을 해체하고 다시 만듭니다.

## 3. 시작합니다

팀을 만든 직후는 「시작 대기」입니다. 리더가 눌러야 1회차가 시작됩니다.

```text
/shareteam start           무엇이 사라지는지 보여 주기만 합니다
/shareteam start confirm   실제로 시작합니다
```

> ⚠ **되돌릴 수 없습니다.** 시작하는 순간 **모든 아이템이 삭제되고**(드랍이 아닙니다) 공유
> 경험치가 0이 되며, 월드 시각이 1일차 아침으로 돌아가고 접속 중인 팀원이 스폰으로 모입니다.
> 그래서 `confirm` 을 붙여야만 실제로 시작합니다.

시작 전에는 증강 구간도, 위치 교환도, 난이도 상승도 돌지 않고 팀원이 죽지도 않습니다.

**첫 회차 전에 한 번만 누릅니다.** 전멸해서 새 월드로 넘어간 뒤에는 저절로 「진행 중」입니다.

## 그다음은

레벨이 오르기 시작하면 [증강](/sharedfate/guide/perks)이 나옵니다. 인챈트와 모루의 비용이
바뀐 것은 [경제 개편](/sharedfate/guide/economy)에 적어 두었습니다.
