# 엔더 드래곤 시련 — 설계

작성 2026-09-28 · 브랜치 `feature/dragon-trials` · **구현 전 설계 문서입니다**

## 무엇을 고치려는가

증강을 여덟 장 쌓은 팀 앞에서 바닐라 드래곤이 너무 쉽다. 광전사(×3) × 무결점(×1.35) ×
암살자(×1.25) = **화력 ×5.06** 이고, 드래곤 머리는 피해 감산이 없어 200 체력이 대여섯 대다.

회차의 마지막 산이 제일 쉬운 구간이 되어 있다.

## 무엇을 만드는가

**엔드에 들어가면 팀 전원이 소환되고, 전투가 진행될수록 팀이 스스로 고른 시련이 쌓인다.**

```
누군가 엔드 포털에 들어감
  ↓  확인 없음 — 엔더런에서 엔드 입장은 원래 돌아올 수 없는 문턱이다
  ↓  다른 팀원에게 3초 예고 → 전원 소환 → 도착 후 3초 무적
  ↓  드래곤 강화 (체력은 팀 인원에 비례)
  ↓  전투가 진행될 때마다 시련 한 장 — 셋 중 하나를 무작위 팀원이 고른다
종료 ─ 드래곤 사망(승리) 또는 팀 전멸(월드 초기화). 그 둘뿐이다
```

**시련은 「위험 + 보상」 한 짝이다.** 증강이 「대가가 따르는 강화」였으니 시련은 그 대칭이다.
크리스탈이 되살아나는 대신 팀 공격력이 오르는 식이라, 고를 때 실제로 고민이 생긴다.

### 왜 이 구조인가

**팀이 위험을 직접 고르기 때문이다.** 예고를 넘어 동의가 된다. 월드가 사라져도
「내가 크리스탈 부활을 골랐다」가 되지 「갑자기 죽었다」가 되지 않는다. 전멸 비용이 월드
전체인 이 게임에서 이 차이는 크다.

부수 효과로 **빨리 깎을수록 위험해진다.** 화력이 센 팀이 시련을 더 빨리, 더 많이 받는다.
팀 실력을 측정하는 코드가 따로 필요 없다.

## 정해진 것

| | 결정 | 근거 |
|---|---|---|
| 엔드 입장 | 한 명이라도 들어가면 **전원 소환**. 확인창 없음 | 엔더런의 엔드 입장은 원래 되돌릴 수 없다 |
| 이탈 | **없다.** 드래곤을 잡기 전에 엔드를 나가는 길은 죽는 것뿐 | 귀환 포털은 드래곤 처치 후 열린다 |
| 시련 선택자 | **무작위 팀원 한 명** (증강과 같은 방식) | 기존 구조 재사용 |
| 시련이 나오는 때 | **시간이 아니라 진행도.** 자리 여섯 곳 | 아래 「자리 여섯 곳」 |
| 시련 성격 | **위험 + 보상 한 짝** | 증강과 대칭. 고르는 재미 |
| 체력 산정 | **팀 인원 비례 고정 배율** | 아래 「체력을 왜 인원 비례로」 |
| 난이도 조절 축 | **시련 누적 하나** | 조절 장치가 둘이면 원인을 분해할 수 없다 |
| 실패의 대가 | **시간 손실 > 자원 손실 > 소량 체력 손실**. 즉사는 쓰지 않는다 | 아래 「즉사를 쓰지 않는 이유」 |
| 광역 피해 | **같은 공격은 팀에게 한 번만** | 아래 「광역 한 틱 한 번」 |
| 통신 규약 | 29 → **30** | 시련 선택 화면과 바닥 표식이 클라이언트에 필요 |

### 체력을 왜 인원 비례로

공유 체력은 **방어에서 인원을 불리하게** 만들지만(맞을 기회가 늘어난다) **공격에서는 인원이
그대로 유리하다**(4명이 때리면 DPS 4배). 체력이 고정이면 4인 전투가 3인보다 짧아져 시련을 덜
본다. 인원 비례로 올리면 전투 시간이 인원수와 무관해진다.

인원은 **팀 명단 기준**으로 센다. 접속 인원으로 세면 전투 중 누가 끊겼을 때 드래곤 체력이
줄어드는 이상한 일이 생긴다.

### 체력은 난이도가 아니라 무대다

조사에서 나온 사실 둘을 붙이면 체력의 성격이 드러난다.

```
착지 이탈 기준 = 최대 체력의 25%   →  드래곤은 체력이 얼마든 착지 4번에 죽는다
착지 중에는 화살이 통하지 않는다    →  때릴 수 있는 시간은 착지 4번뿐
```

즉 **체력을 올려도 전투 시간은 비례해서 늘지 않는다.** 시간을 잡아먹는 것은 공중 대기이지
체력이 아니다. 체력은 **패턴을 보여줄 시간을 사는 비용**이고, 어려움은 전부 시련이 담당한다.

전투 길이를 실제로 늘리려면 체력과 함께 **착지 빈도**를 만져야 한다. 착지 중에는 근접이
가능하므로, 착지를 늘리면 전투가 길어지면서도 「계속 싸우는」 형태가 된다. 반대로 공중 체류를
늘려 시간을 벌면 할 일이 없어 지루해진다 — 바닐라 드래곤이 지루한 이유가 그것이다.

### 즉사를 쓰지 않는 이유

체력 20 공유 + 전멸 시 월드 삭제면 **「즉사」는 이미 시스템이 제공하고 있다.** 패턴까지 즉사를
담당하면 과적이다. 패턴은 누적으로만 벌하고, 실패의 대가는 이 순서로 준다.

```
① 시간 손실 — 드래곤 회복, 크리스탈 재생, 진행도 후퇴
② 자원 손실 — 내구도, 화살, 위치
③ 체력 손실 — 마지막 수단, 소량·누적형
④ 즉사 — 쓰지 않는다
```

### 광역 한 틱 한 번

지금 `StatMirror.fold` 는 팀원별 체력 손실을 **그대로 합산**한다. 그 판단 자체는 옳다 — A 가
좀비에게, B 가 스켈레톤에게 맞았으면 팀은 진짜로 두 번 맞은 것이다. 공유된 상태이상처럼
합산하면 안 되는 경우는 `SharedEffectDamage` 가 대표 한 명만 남기고 막는다.

**문제는 드래곤 날갯짓이 그 둘 사이에 있다는 것이다.**

| 상황 | 지금 | 옳은가 |
|---|---|---|
| A 는 좀비, B 는 스켈레톤에게 피격 | 합산 | 맞다 |
| 공유된 독이 전원에게 틱 | 대표 한 명만 | 맞다 |
| **날갯짓 한 번에 4명이 닿음** | **합산 (5×4=20)** | **틀렸다** |

하나의 공격인데 네 번 맞았다고 세면 팀 체력 전부가 날아간다. 이 상태로 광역 패턴을 얹으면
피해를 아무리 낮춰도 **4명이 함께 맞는 순간 무조건 전멸**이라 설계가 성립하지 않는다.

**그래서 세 번째 분기를 넣었다 — 같은 공격원에서 같은 틱에 온 피해는 첫 한 번만 반영한다.**
장비도 공유라 팀원들의 방어구가 같고, 따라서 누가 대표로 맞든 들어가는 피해가 같다. `SharedEffectDamage` 와 같은 결이고, 드래곤뿐 아니라 크리퍼·위더 폭발 같은 기존
광역 사고에도 함께 듣는다.

> 이 변경은 「4명이 뭉쳐 있으면 위험하다」는 지금의 긴장을 없앤다. 그것을 이 모드의 맛으로
> 볼 여지도 있었으나, 광역 패턴을 넣기로 한 이상 양립할 수 없어 이쪽을 골랐다.

## 자리 여섯 곳

**타이머를 쓰지 않는다.** 시련은 전투가 실제로 진행돼야 나온다.

```
엔드 입장 → 첫 크리스탈 → 크리스탈 전멸 → 체력 80% → 50% → 30%
```

크리스탈이 살아 있으면 드래곤 체력이 잘 안 깎이므로 대체로 이 차례가 되지만, 순서를 코드가
강제하지는 않는다.

**시계 대신 체력 막대를 본다.** 다음 시련이 언제 올지 알 수 있어 대비가 되고, 「반쯤 깎았더니
판이 바뀐다」가 시간이 흐른 것보다 훨씬 읽힌다. 크리스탈에도 의미가 생긴다 — 깨는 행위에
대가가 붙으면 순서와 속도를 판단하게 된다.

**방향이 뒤집힌다.** 빨리 깎을수록 시련을 빨리 받는다. 잘하는 팀이 더 위험해진다.

### 한 번만 센다

드래곤은 크리스탈로 회복해 체력이 문턱을 오르내린다. 처음 내려간 한 번만 세지 않으면 후반에
같은 자리가 계속 터진다.

### 관통하면 줄을 세운다

화력이 센 팀은 80%에서 30%까지 한 번에 깎을 수 있다. 셋을 한꺼번에 띄우지 않고 차례로 낸다 —
앞 선택을 끝내야 다음이 뜬다. **빨리 깎은 대가는 치르게 하되** 전투 중에 선택창이 겹치지는
않게 한다.

### 풀을 나눈다

입장 직후와 체력 30% 는 같은 무게일 수 없다. 자리마다 풀을 따로 두면 난이도 곡선이 생긴다.
카드 하나가 여러 풀에 속할 수 있어 「80·50·30 을 한 묶음으로」도 「30% 에만 나오는 카드」도
만들 수 있다.

**풀이 비어 있으면 아무것도 주지 않고 지나간다.** 카드를 채워 가는 동안에는 빈 풀이 정상이다.

## 시련은 데이터다

증강과 같은 구조로 만든다. `sharedfate-trials-default.json` 이 카드를 들고, 코드는 읽을 뿐이다.

```json
{
  "id": "sharedfate:trial_lightning_trail",
  "name": "지나간 자리",
  "icon": "minecraft:lightning_rod",
  "description": "8초마다 각자가 1초 전 있던 자리에 번개가 떨어집니다. 대신 팀이 15% 빨라집니다.",
  "risks":   [ { "type": "dragon_delayed_strike", "interval": 160, "delay": 40, "damage": 4 } ],
  "rewards": [ { "type": "attribute", "attribute": "minecraft:movement_speed",
                 "operation": "add_multiplied_total", "amount": 0.15 } ]
}
```

**`rewards` 는 새 코드가 필요 없다.** 기존 증강 효과 타입 92개를 그대로 쓴다.

**`risks` 만 새 코드다.** 카드마다 하나씩 만들 필요는 없고, 범용 타입 몇 개를 값으로 변형한다.

| 위험 타입 | 값으로 바뀌는 것 |
|---|---|
| `dragon_delayed_strike` | 주기 · 예고 시간 · 피해 · 표식 모양 |
| `dragon_focus_target` | 대상 수 · 지속 · 갱신 주기 |
| `dragon_breath_field` | 웅덩이 크기 · 지속 · 피해 |
| `dragon_phase_bias` | 착지 빈도 · 공중 체류 시간 |
| `dragon_crystal_revive` | 부활 개수 · 간격 · 회복량 |
| `dragon_regen` | 초당 회복량 |

카드 뽑기는 **아직 안 고른 것 중 셋**이고, 고른 것은 전투가 끝날 때까지 **쌓인다**.

## 패턴 설계 규칙

기존 모드 다섯과 협동 보스 설계론을 조사해 얻은 규칙이다. **카드를 만들 때마다 이 목록을
통과시킨다.**

### 반드시 지킨다

1. **고정 순환으로 돈다.** 확률 발동이 아니라 정해진 순서와 간격. 외울 수 있어야 회피할 수
   있고, 회피할 수 있어야 월드가 날아가도 억울하지 않다
2. **경고는 하나의 규격으로 통일한다.** 소리 · 자막 · 바닥 표식 3종을 공용 경고 API 로 만든다.
   플레이어가 경고 하나만 배우면 모든 패턴에 통한다. 패턴을 늘릴 때 공짜로 따라온다
3. **예고 시간을 행동에 맞춘다**

   | 요구 행동 | 최소 예고 |
   |---|---|
   | 제자리 옆걸음 | 30틱 (1.5초) |
   | 지정 위치로 이동 | 50틱 (2.5초) |
   | 4인이 흩어져야 함 | 80틱 (4초) |
   | 페이즈 전환 | 100틱 (5초) |

4. **같은 표식은 언제나 같은 결과.** 색을 먼저 고정한다 — 빨강 = 서 있으면 죽음 / 노랑 = 서
   있어야 함 / 파랑 = 밀려남 / 보라 = 한 사람 지정
5. **다음 행동을 공개한다.** 보스바에 `엔더 드래곤 — 다음: 착지 (12초)`. 월드 삭제 게임에서
   「몰라서 죽었다」를 없애는 가장 싼 방법이다
6. **착지를 확률에서 결정론으로.** 지금은 7.7~33% 확률이라 계획을 세울 수 없다
7. **패턴은 저위력 버전으로 먼저 선보인다.** 죽으며 배울 수 없으므로 학습을 전투 앞쪽으로
   당긴다
8. **역할을 고정하지 않는다.** 5분 위치 교환이 있는 판에서 「궁수 담당」은 성립하지 않는다.
   「지금 그 자리에 있는 사람이 하는 일」로 설계한다

### 쓰지 않는다

- **즉사 메커닉** — 0개
- **피해 분할형 스택·소크** — 공유 체력에서 효과가 정확히 0 이다. 4명이 5씩 나눠 맞아도 팀은
  20 깎인다. 인원 수를 통과 조건으로 쓰는 자물쇠 형태로만 허용
- **방패 무시 · 무적시간 무시** — 무적시간 무시는 연타를 누적시켜 회피해도 죽게 만든다
- **강한 넉백** — 엔드 섬 밖 허공으로 날아가면 대응 불가 즉사다
- **난이도 스케일링에 얹힌 피해** — 하드코어는 난이도가 어려움 고정이라 정한 값이 ×1.5 가 된다
- **인원 수로 나뉘는 총량형 과제** — 인원 페널티를 가중시킨다
- **시선 어그로 잡몹(엔더맨)** — 통제 불가한 피해원

### 인원 페널티를 뒤집는 유일한 구조

**병렬 과제.** 진행도가 인원 수로 나뉘지 않는 과제를 4개 두면 4인이 정확히 4배 빠르다.
「4명이 각각 다른 크리스탈을 동시에」 같은 형태. 인원이 많을수록 불리한 이 모드에서 이것만이
깨끗하게 균형을 되돌린다.

### 안전장치

- **마지막 숨** — 팀 체력이 2 이하로 떨어지면 전원 40틱 무적 + 드래곤 강제 이륙. 전투당 1회,
  확률 없음. 이것 하나로 억울한 전멸의 대부분이 사라진다
- **공허 낙하 보호** — 아레나 밖으로 나가면 되돌린다. 사고로 월드가 지워지면 설계 실패다
- **위치 교환 예고** — 전투 중 교환은 10초 전 예고 + 교환 후 40틱 무적. 브레스 한가운데로
  순간이동하는 사고를 막는다

## 설정

```json
"dragonHealthPerMember": 600      // 팀 인원당. 0 이면 이 기능 전체가 꺼진다
```

설정이 하나뿐이다. 시련이 나오는 자리가 여섯 곳으로 고정이라 간격도 상한도 필요 없다. 별도
on/off 도 두지 않는다 — 0 이면 꺼진다.

세션 상태(터진 자리·줄·누적 시련)는 `sharedfate-dragon-trial.json` 에 저장해 **서버 재시작에도
살아남게** 한다. 저장하지 않으면 체력만 강화된 채 자리가 0 인 어긋난 상태가 된다.

## 경계

| 조각 | 하는 일 | 모르는 것 |
|---|---|---|
| `DragonTrialSession` | 터진 자리·줄·누적 목록 | 시련이 무슨 효과인지 |
| `TrialDraft` | 셋을 뽑고 선택을 받음 | 드래곤을 모름 |
| `TrialRegistry` | JSON 을 읽어 카드 목록을 들고 있음 | 전투를 모름 |
| 위험 효과들 | 낙뢰·표적 같은 동작 하나씩 | 서로를 모름 |
| `EndArrival` | 엔드 입장 감지와 전원 소환 | 시련을 모름 |
| 공용 경고 | 소리·자막·바닥 표식 | 무엇을 경고하는지 모름 |

## 아직 정하지 않은 것

- **시련 카드 목록** — 사람과 함께 정한다. 틀이 데이터 기반이라 나중에 몇 장이든 늘릴 수 있다
- **전투 목표 길이** — 조사 통설은 5~7분(8~10분을 넘으면 기량이 아니라 지구력 시험이 된다).
  처음 잡았던 10~15분보다 짧다. 실제 플레이로 정한다
- **정확한 수치 전부** — 설정값으로 두고 플레이하며 조정한다. 설계가 책임질 것은 값이 아니라
  값을 쉽게 바꿀 수 있는 구조다
- **클라이언트 화면 세부** — 시련 선택 화면은 증강 화면을 재사용할 수 있는지부터 확인한다
