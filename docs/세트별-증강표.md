# 세트별 증강표

정의 파일에서 그대로 뽑은 표입니다. **손으로 고치지 마십시오** — 다시 뽑으면 덮어써집니다.
증강을 고쳤으면 `src/main/resources/` 의 정의를 고친 뒤 이렇게 다시 뽑습니다.

```
python docs/세트별-증강표-생성.py
```

> **증강을 고쳤는데 이 표를 다시 안 뽑으면 그대로 낡습니다.** 표와 정의가 어긋나면 표를
> 보고 잘못 판단하게 되므로, 증강·세트 정의를 건드린 판에서는 반드시 함께 뽑으십시오.

모두 **96개**입니다 — 실버 35 · 골드 36 · 프리즘 25.
